# AllTerrain Forms: MIO knowledge base

These linked Markdown files are bundled with the form editor and registered as private window documents. MIO search_help searches headings/text and read_help reads individual files; there is no remote documentation fetch. Files are kept below the current API's 12,000-character read limit.
